# Reproducibility — HOL-01 v1.1.1

The public result is a finite exact certificate. Python 3.10+ and the standard library are sufficient.

## One-command replay

```bash
./VERIFY_LOCAL.sh
```

Equivalent commands:

```bash
python3 hol01_certificate.py --check RESULTS.json
python3 independent_p7_permutation_check.py
python3 finite_prime_regression_check.py --check FINITE_REGRESSION_RESULTS.json
```

Expected terminal lines:

```text
HOL-01: ALL ASSERTIONS PASSED
independent p=7 permutation check: ALL ASSERTIONS PASSED
HOL-01 finite-prime regression check: ALL ASSERTIONS PASSED
```

## Principal certificate

`hol01_certificate.py` constructs the finite orbit graphs and the root-fibre action exactly. The principal publication case is p = 7. It verifies the orbit cardinalities, uniform fibre degree, root fibre, affine Schreier action, monodromy order 686, translation kernel order 49, linear-image order 14, a zero-translation complement, and the order-343 subgroup generated by `BABC` and `BABAA`.

`RESULTS.json` is the deterministic snapshot for this release of the principal certificate.

## Independent p = 7 cross-check

`independent_p7_permutation_check.py` deliberately avoids the affine-coordinate closure routines. It constructs the 49 lifted fibre points directly, realizes the Schreier loops as permutations, and independently recovers the orders 686 and 343.

## Finite-prime regression checker

`finite_prime_regression_check.py` performs exact finite checks at p = 3, 5, 7, 11, 13. It also checks one higher step `Gamma_{p^3} -> Gamma_{p^2}` at p = 3, 5, 7. The output is `FINITE_REGRESSION_RESULTS.json`.

These computations are regression/exploratory evidence only. They are **not** a proof of a theorem for every odd prime and **not** a proof of stability at every congruence level.

## Integrity

Run:

```bash
sha256sum -c SHA256SUMS.txt
```

The checksum file covers all release files except itself.
